# Pronoy Shaha - Portfolio Website

Personal portfolio website of **Pronoy Shaha**, Software Engineering student at Daffodil International University.

## Features
- Fully responsive (Mobile + Desktop)
- Dark theme with modern UI
- Smooth scrolling & animations
- Typing effect in hero section
- Contact form (opens email client)

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)

## How to Deploy

### GitHub Pages / Vercel
1. Create a new repository on GitHub
2. Upload all files of this folder
3. Connect the repository to **Vercel** (recommended) or enable GitHub Pages

### Local Preview
Just open `index.html` in your browser.
